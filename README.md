# Velatura

A GNOME app that applies one color theme to the whole desktop from one place.

The documentation is HTML and lives in [`docs/`](docs/index.html):
read it online at <https://rafael0rueda.github.io/Velatura/>.

- [Plan](https://rafael0rueda.github.io/Velatura/plan.html)
- [Architecture](https://rafael0rueda.github.io/Velatura/architecture.html)
- [Interface guidelines](https://rafael0rueda.github.io/Velatura/hig.html)
- [Changelog](https://rafael0rueda.github.io/Velatura/changelog/index.html)

Status: in development. The engine and the `velatura` command exist; the app window does not yet.
