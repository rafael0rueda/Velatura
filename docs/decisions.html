D1Clean, independent project. Aetherius and Ember are imported as bundled themes.DecidedThe old scripts recolour files in place by matching hex values, which cannot be made safe for other people's machines. Nothing in that repository is modified.
D2Audience: GNOME users in general.DecidedDrives capability detection, translations, accessibility, and the rule that theme files are untrusted.

Aetherius and Ember ship as two themes, paired by default.DecidedOwner chose two themes. The format still allows a theme with several variants. Both palettes are dark, so day/night is not light/dark.
D6Switching: manual, scheduled, or following the GNOME dark style (light and dark pairs only).Decided, detail ProposedOne systemd user timer runs an idempotent switch auto. Unattended runs never ask; they skip and record.

Wallpaper and fonts are chosen by the user among what is installed and stored with the user's settings, not in themes.Decided, detail ProposedSuggestions are advisory and applied only after the user accepts them once. The user can always decline and add the line themselves.Proposed (owner asked which way is better)Smallest footprint in the user's file, and how Kitty's own theme tool behaves.
