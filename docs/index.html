The plan in brief

  • Stack: Rust engine and CLI; GTK4/libadwaita GUI, in Rust unless a Phase 0 spike says otherwise; an optional small GNOME Shell extension in JavaScript.
  • Theme format: one TOML file per theme: named colours, fixed roles that refer to them, 16 terminal colours. Colours and short names only.
  • MVP, in four slices: engine and CLI with Kitty and the system accent and dark style; then Ghostty, GTK4/libadwaita and GTK3; then the GUI; then GNOME Shell through User Themes. Backups, preview, undo and restore from the first slice.
  • Honest limits: recolouring libadwaita apps and the Shell is unofficial and can break with GNOME updates. The Shell shows the nearest system accent, not the exact one. GTK3 needs the adw-gtk3 theme. Open apps keep their colours until restarted. The lock and login screens cannot be themed.
  • On this machine: existing settings would override the new theme in GTK, Kitty and Ghostty, and the old theme timer is still active. Both are handled in the plan and need a decision from you.
